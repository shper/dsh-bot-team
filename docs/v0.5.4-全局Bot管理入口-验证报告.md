# v0.5.4 全局 Bot 管理入口 — 验证报告

> 状态：**✅ 完成**。左侧栏底部新增全局 Bot 管理入口（图标按钮），打开「Bot 管理（全局）」弹窗，
> 可查看/新建/编辑/删除全局 Bot 并看到每个 Bot 所属的群；图标经两轮调整后由用户确认清晰。
>
> 证据：`bot-team/client.js`；真机 UI 用户确认。

---

## 1. 功能

- **入口**：左侧栏（群聊列表）底部新增「Bot 管理（全局）」按钮，与群列表同区、固定在底部（最终按反馈改回文字按钮）；
  - 图标：机器人头像（天线/眼睛）+ 右侧三条列表行，语义为 "Bot 列表 / 全局 Bot 管理"（第一版仅机器人头，用户反馈寓意不明，已改为组合图形）；
  - tooltip/aria-label：`Bot 管理（全局）`。
- **弹窗「Bot 管理（全局）」**：
  - 列出全部全局 Bot：名称、能力档位徽标、`provider/model`、所属群（群名列表或「未加入任何群」）；
  - 操作：`编辑`（复用现有 Bot 编辑对话框，改模型/能力/SOUL/AGENT）、`删除`、底部 `+ 新建 Bot`、`关闭`；
  - 删除前 `window.confirm` 二次确认，并明确提示：若 Bot 正在 N 个群中，删除会同时把它移出这些群；
  - 编辑/新建/删除后刷新全局数据。
- 后端复用已有 `bot.delete` action：停止该 Bot 在群内的运行中 turn、释放成员 session、删除成员关系后再删除 Bot 记录。

## 2. 验证

- 用户确认：左下角入口显示正常、图标语义清楚、点击可打开管理弹窗；列表/编辑/新建入口正常。
- 无宿主崩溃（未改 Host 逻辑；仅新增 UI 与复用既有 action）。
- 说明：删除的级联行为由既有 `bot.delete` 实现（停止成员 turn → dispose session → 删成员 → 删 Bot），本次未新增自动化用例。

## 3. 已知限制

- 管理弹窗不展示 SOUL.md/AGENT.md 内容预览（编辑对话框内可改）；
- 删除为不可恢复操作（有二次确认 + 群影响提示）；
- 全局 Bot 的会话是按群/成员独立的，管理弹窗不直接提供会话入口（在群成员卡片「查看会话」）。
