# v1.2.1 会话历史与用量修复

源码版本从 `1.2.0` 升级为 `1.2.1`。

- 修复执行记录查询的服务访问与日志分页，原消息关联的历史执行可以继续读取。
- 完整会话使用独立只读页面，包含所有历史轮次和明确的返回入口；返回后保留原执行按钮、聊天草稿、滚动位置和聊天选择。成员卡片与侧栏入口使用同一历史读取方式。
- Bot 回复完成以及事件连接恢复后，右侧 Token 累计用量会自动刷新；并行完成时合并刷新请求，过期响应不会覆盖新数据。
- 移除每小时回复轮数限制，保留每日 Token 预算、并行限制和串行调度。

验证：`npm run check` 与 `npm test` 通过，共 305 条测试，304 通过、0 失败、1 条按条件跳过。隔离浏览器实际验证了完整页面打开、连续返回与再次打开、草稿和滚动位置保留、跨聊天历史查看、错误返回及请求取消。

更新本地链接安装后，需要重新加载插件 Host 或完全退出并重开 DSH，以更新包版本和客户端快照；仅刷新页面不能保证加载新代码。
