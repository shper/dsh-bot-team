# v0.6.5 左侧群栏收起 — 变更记录

> 状态：代码已完成，`node --check` 与 `node --test` 通过；已用真实 `GroupList` 组件做浅色/深色静态渲染截图检查。
> 目标：左侧群栏可以在「展开（群名 + 预览）」与「收起（仅图标）」之间切换，收起后把宽度还给消息区；刷新/重新打开页面后记住上次状态。

## 1. 交互

- 展开态（默认）头部：左侧 `群聊`，右侧新增一个描边面板图标（`收起侧栏`），旁边仍是 `+ 新建`。
- 点击后侧栏从 `264px` 收成 `68px` 的图标栏，宽度带 `180ms` 过渡：
  - 群列表只保留群头像（自定义图片 / 插画 / 首字渐变），不再显示群名、时间、最后消息、成员数。
  - 选中群仍是淡蓝圆角底；有 Bot 回复中的群，头像右下角保留绿色状态点。
  - 每个头像的 `title` 为「群名 + 最后一条消息」，鼠标悬停即可看到；`aria-label` 提供同样的可访问名称。
  - 头部只保留「展开侧栏」和「新建群 / 话题」两个图标按钮。
  - 底部 `Bot 管理` / `设置` 变成上下排列的图标按钮，`title` / `aria-label` 保留完整含义。
- 再点「展开侧栏」回到原来的群列表布局。
- 设置保存在浏览器 `localStorage` 的 `bot-team.sidebar.collapsed`（`'1'` / `'0'`），刷新页面、切走再回来都保持；存不了（隐私模式、禁用存储）时静默降级为仅当前会话生效。

## 2. 可访问性

- 切换按钮是 `<button>`，带 `aria-label` / `title`（收起侧栏 / 展开侧栏）、`aria-expanded` 和 `aria-controls="bt-group-sidebar"`。
- 收起态所有按钮都是纯图标，但都保留 `aria-label` 或 `title`，不会出现无名按钮。
- 群项补了 `role="button"`、`tabIndex=0`、`aria-current`，支持 `Enter` / `Space` 选群，并有 `:focus-visible` 焦点环；展开态同样受益。
- `prefers-reduced-motion` 下关闭宽度过渡。

## 3. 实现

- `client.js`
  - `SIDEBAR_COLLAPSED_KEY`、`readSidebarCollapsed()`、`persistSidebarCollapsed()`：localStorage 读写与异常兜底。
  - `initialState.sidebarCollapsed` + reducer `toggleSidebar`：状态走既有 reducer，页面重渲染即可，无需新增 Host 字段或 HTTP 路由。
  - `BotTeamPage`：`useReducer` 初始化函数在**每次挂载**时重新读取 localStorage（避免模块级快照导致切走再回来状态倒退）；`sidebarCollapsed` 变化时写回 localStorage。
  - `GroupList`：按 `state.sidebarCollapsed` 渲染展开头部/列表/底栏或图标栏；头像 `GroupAvatar` 复用，不新增资源。
  - `S.sidebar(collapsed)`、`S.railHeader`、`S.groupRail`、`S.railItem`、`S.sidebarActionsCollapsed`、`S.railAction` 等样式；`GLOBAL_CSS` 增加 `bt-sidebar` / `bt-sidebar-toggle` / `bt-group-rail` / 焦点环 / reduced-motion。
- `test/client-harness.js`：把 localStorage 注入 VM，导出读写函数，并支持 `remount()` 验证挂载时重读，供新测试使用。
- `test/sidebar-collapse.test.js`（7 条）：展开态结构、收起态仅图标与 tooltip、切换/选群/键盘事件、两种布局的新建入口、reducer 不可变更新、localStorage 读取/写入/异常降级、页面挂载时重读偏好。

## 4. 验证

- `node --check bot-team/client.js` 通过；
- `node --test bot-team/test/*.test.js`：80 条全部通过（原 73 + 新增 7 条）；
- 用真实 `GroupList` 渲染静态预览，确认浅色/深色下 264px 与 68px 的头部、头像列、底栏对齐与选中态正常（预览脚本与截图已清理，不属于发布产物）。

## 5. 注意

- 群栏收起状态是浏览器本地偏好，不写入 Bot Team storage domain，不会跟随账号同步到其他设备。
- 收起/展开会重建列表 DOM，长列表的滚动位置会回到顶部；当前群选中状态不受影响。
- 移动端（窄屏）没有自动收起逻辑，仍由用户点按钮决定；右侧成员栏在 `max-width: 1100px` 下保持原有的自动隐藏规则。
