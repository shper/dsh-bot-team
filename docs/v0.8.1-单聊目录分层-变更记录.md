# v0.8.1 单聊目录分层

> 版本号：docs 内部迭代 `v0.8.1`；对应首个公开发行版 npm 包 `dsh-bot-team@1.0.0`。

> 状态：代码与测试完成；需完整重启 DSH 后由启动迁移把现有单聊目录折进 `direct/`。

## 变更

单聊工作目录从 `<dataDir>/<botId>/` 改为 `<dataDir>/direct/<botId>/`，与群聊的 `<dataDir>/groups/<groupId>/` 形成两个明确的分类层：

| 路径 | 用途 |
|---|---|
| `<dataDir>/bots/<botId>/BOT.md` | 人格与工作规范 |
| `<dataDir>/direct/<botId>/` | 单聊工作目录 |
| `<dataDir>/groups/<groupId>/` | 群聊工作目录 |

`<dataDir>` 仍是 `config.dataDir`，默认 `$DSH_HOME/dsh-bot-team`。群聊目录名保持 `groups/` 不变。

## 迁移

`migrateLegacyLayout` 在原有迁移之外新增一步：群记录里 `workspaceCwd` 恰好等于 `<dataDir>/<botId>` 的单聊，目录移动到 `<dataDir>/direct/<botId>` 并改写记录；外部自定义工作目录仍不动。迁移幂等，重启后自动执行。

单聊的 session cwd 与新目录不一致时，仍按 v0.8 的规则重建 session（单聊消息都在 domain 里，DSH 会话历史重开）。

## 验证

- `node --test bot-team/test/*.test.js`：111 条全部通过。
- `workspace-layout` 新增用例：v0.8.0 的 `<dataDir>/<botId>` 目录及其文件被移入 `direct/`，旧路径消失，记录改写；第二次迁移无操作。
- `service-integration` / `direct-groups-host` 断言单聊默认目录为 `<dataDir>/direct/<botId>`。

## 重启后检查

1. `$DSH_HOME/dsh-bot-team/direct/<botId>/` 存在，旧的 `$DSH_HOME/dsh-bot-team/<botId>/` 不再保留。
2. 单聊首次回复正常；若之前在旧目录有过会话，`member.sessionId` 会更新，旧 session 文件保留。
3. 群聊路径与数据不受影响。
