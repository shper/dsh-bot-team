# v0.5.5 UI 风格统一（美化）— 变更记录

> 状态：已安装，等待视觉确认。仅前端样式调整，无 Host 逻辑/数据变更。

## 变更

- 统一视觉 token：字体、字号、间距、圆角、边框、阴影。
- 左侧群列表：浅灰分层背景；选中项=淡蓝底 + 细边框 + 标题蓝色（按反馈已去掉左侧蓝色竖条）；悬浮浅灰反馈；列表底部 Bot 管理图标入口。
- 右侧成员/任务面板：白色圆角卡片 + 弱阴影 + 统一卡片间距。
- 按钮：白底细边 + 悬浮/按下反馈；主按钮统一蓝色；危险操作红色描边。
- 消息区：气泡改为圆角卡片（用户浅蓝、Bot 白底 + 左侧色条），元信息与 token 信息弱化。
- 输入区：圆角输入框 + focus 蓝色描边光晕；@ 选择器、弹窗、滚动条统一风格。
- 全局注入 `.bt-root` 样式表：按钮 hover/active/focus-visible、输入 focus、滚动条。

## 验证

- 客户端语法检查通过、插件重装成功、无宿主崩溃。
- 待用户视觉确认；若需细化可继续调整具体区块（颜色、密度、字体大小等）。
