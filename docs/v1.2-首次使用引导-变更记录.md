# v1.2 首次使用引导 — 变更记录

> 当前源码版本：`dsh-bot-team@1.2.0`，从 `1.1.0` 升级。范围包括首次使用欢迎页、三步引导、侧栏调整，以及群聊任务面板移除。
> 本记录描述源码与验证结果；npm 安装示例需在该版本发布后使用，发布前可安装本地源码目录。

## 首次使用与创建入口

首次使用且没有会话时显示「开始使用」欢迎页，以 **创建 Bot** 为主入口、**创建群聊** 为次入口；没有 Bot 时展示「创建第一个 Bot」与「推荐第一步」。首页下方的研究员、工程师、审阅者是协作示例，展示如何用多个 `@` 分工。

- **创建 Bot** 打开现有的正式创建表单，成功后自动打开新 Bot 的单聊；单聊发消息无需 `@`。
- **创建群聊** 打开现有建群表单，成功后进入新群，可随后添加 Bot。
- 取消创建会留在欢迎页；查看欢迎页、协作示例或引导不会自动创建 Bot、群或任务。
- 欢迎页不再显示右侧 Bot 库；全局 Bot 管理继续从侧栏底部进入。

右上角 **快速上手** 打开「三小步，开启协作」引导：

1. **先认识一位 Bot**：选择模型、名字与专长，创建后获得单聊。
2. **为共同的目标，建一个群**：邀请不同专长的 Bot，同一个 Bot 可参与多个群。
3. **用 @ 邀请它们参与**：让 Bot 讨论问题、处理任务或检查彼此的工作。

引导内也有 **创建 Bot / 创建群聊** 按钮，可直接进入相应表单。

## 返回首页与界面适配

- 侧栏新增 **开始使用**，可从单聊或群聊返回欢迎页；主动选择首页后，后台数据刷新、会话重新排序或短暂空响应都不会自动打开会话。这里的保持针对后台数据刷新，不是跨页面重载的首页偏好。
- 返回首页保留已有会话缓存、消息、讨论状态和界面偏好。已有用户首次载入仍沿用原有会话选择逻辑，不强制改为首页。
- 创建 Bot 后会等待新单聊出现在刷新数据中再进入；等待期间手动选择首页或另一会话时，以用户的新选择为准。
- 左侧栏当前展开宽度为 **232px**，收起后为 **68px**；底部 **Bot 管理 / 设置** 上下排列。单聊与群聊空态上方的装饰短横线、侧栏底部标语与其分隔线已移除。
- 欢迎页和引导跟随 DSH 的 **zh/en** 与 **light/dark** 设置；布局随可用宽度调整，窄屏卡片改为单列，并通过顶部导航按钮展开侧栏。

## 任务能力与右侧面板

群聊右侧的任务面板和「新建任务」入口已移除。群成员、讨论和单聊信息面板，以及 Bot 回复上的任务状态标记继续保留。

任务数据与后端能力继续可用：通过 `bot_team_task_create`、`bot_team_task_list`、`bot_team_task_update` 或 HTTP action 创建、查询、编辑、派发、中断、评审、验收与返工；优先级、DAG 依赖、验收后解锁、队列和 `dispatch_ready` 批量派发能力保留。原有任务不因移除界面而删除。

## 升级说明

安装 `1.2.0` 源码后，重新加载插件 Host（disable → enable 或重启 DSH），再刷新现有 GUI 页面。Host 在加载时读取包元数据，「关于」中的版本号需要 Host 重载后才会更新；只刷新浏览器不足以更新它。

沿用 v1.1 的中英双语、PDF 导出及 `fontkit` 依赖；从源码安装时仍需在包目录安装依赖。历史行为与限制见 [v1.1 中英双语与导出 PDF](<v1.1-i18n与PDF-变更记录.md>)，安装与升级步骤见 [使用指南](<使用指南.md>) 和 [升级检查清单](<升级检查清单.md>)。
