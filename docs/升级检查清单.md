# Bot Team 升级检查清单

> DSH 处于 `0.2.1-rc.x` 快速迭代期。升级 DSH 后建议按本清单跑一遍；任何一项失败都先停用插件并检查对应契约。
> 自动化手段：把 `cordis.patch.yml` 的 `smokeTest` 设为 `true` → remove/install（或重启）→ 查看 `<workspace>/.bot-team/smoke.jsonl`。
> 冒烟会真实调用 LLM（约 10+ turn，注意 token），验证完成后把 `smokeTest` 改回 `false`。

## 1. 依赖的 DSH 契约（升级重点观察）

| 契约 | 用途 | 验证方式 |
|---|---|---|
| `ctx.agents.create/resume(options)` | 创建/恢复 Bot Agent | 冒烟 `host.bot.created/resumed` 活着；`smokeTest` 全绿 |
| `AgentOptions{provider,model,reasoningEffort,maxTokens}` | 每 Bot 独立模型 | `request/header` 与请求路由一致（冒烟 `requestHeaderRoute`） |
| `meta{origin:'subagent', agentPreset, cwd}` | 会话隐藏、全能力 preset、工作目录 | 侧栏不出现 Bot 会话；session header 含 origin |
| `agent.followup(完整 UserMessage)` | 驱动一轮对话 | 冒烟 `mentionReply`；注意必须传 `{role,id,content,source}` |
| `session/event`（assistant/message、turn/end） | 捕获回复与完成 | 冒烟回复文本、usage 正确 |
| `agent/assistant-stream`（agent 作用域） | 流式输出 | UI 实时流式；断流可重连 |
| `ctx.systemPrompt.section/context`（agent 作用域） | 人格与群上下文 | `personaInSystemPrompt`；改 BOT.md 后下一轮生效 |
| `ctx.agentPresets.mount` | 全能力 preset 挂载 | Bot 工具可用（文件/搜索/联网/命令） |
| `ctx.tools.register/restrict/guard` | 模型工具、Bot 工具限制 | `modelToolsRegistered`；Bot 不可递归调用 Team 工具 |
| `session.append('sandbox/mode')` | Bot 沙箱档位 | session JSONL 出现 workspace-write；冒烟 `sandboxTierWorkspaceWrite` |
| `ctx.connection.fetch.register` | `/api/bot-team.*` 路由 | 无 Cookie 401；页面内 200；SSE 正常 |
| `ctx.storageDomain.open`（per-record） | 群/单聊/分组/Bot/消息/讨论/任务持久化 | 冒烟 domain CRUD；schema v6（旧数据自动迁移） |
| 任务依赖/优先级（`dependsOn`、`priority`） | 任务板 DAG 与排序 | 冒烟 `taskPrioritySort` / `taskDependencyGating` / `taskDependencyCycleRejected` / `taskAutoUnblock` |
| Engine `taskHook` 异步安全 | 任务记账不崩宿主 | 验收带依赖者任务后宿主不退出（B7 回归） |
| `queueSnapshot` / `maxParallelTurns` | 队列展示与并发上限 | 冒烟 `taskQueueSnapshot`；一键派发后 UI 显示执行中/排队 |
| `abortJob` / `cancelTaskRun` | 任务进行中中断 | 派发长任务后「中断」，任务 cancelled 且不再产出交付 |
| 任务 `meta.taskId` 与 `turn/end` 回填 | 任务交付↔消息关联 | 冒烟 `taskFlowAccepted` / `taskChangesAndRework` |
| `SessionHeader.origin` 侧栏过滤 | Bot 会话隐藏 | 左侧会话列表无 bot session |
| `ctx.uiWorkspace.openSession(sessionId)` | 查看 Bot 会话 | 成员卡片「查看会话」可打开 |
| `ctx.sessionController.modelCatalog()` | 模型下拉 | 新建/编辑 Bot 的模型列表非空 |
| `ctx.slots.inject/register`（main / sidebar.panellist） | 页面与入口 | `cordis_inspect_query client Slots.listSubTree{root:"sidebar.panellist"}` 可见 `bot-team` |
| `@deepseek-ai/dsh-client-ui-*` 模块加载 | Client bundle | 刷新后页面正常、无控制台报错 |

## 2. 升级后逐项检查

1. **插件状态**：插件管理页/`plugin_manager list_plugins` 中 `bot-team` 为启用；`Config.listConfigs{name:'dsh-bot-team'}` 有行。
2. **入口与页面**：左侧栏有 Bot Team 图标；点击后页面渲染（无白屏）。
3. **健康接口**：`GET /api/bot-team.health` 在页面内经 `fetch` 可访问；无 Cookie `curl` 返回 401。
4. **数据**：`health.domain.schemaVersion` ≥ 6，counts（含 tasks、folders）与 `~/.dsh/storages/bot_team` 文件数一致；旧群/消息/任务可打开；启动迁移后每个旧 Bot 自动生成一个单聊（`grp-dm-<botId>`）且各有一个成员。
4b. **目录布局（v0.8.1）**：`$DSH_HOME/dsh-bot-team/bots/<botId>/BOT.md` 存在；每个群的工作目录是 `$DSH_HOME/dsh-bot-team/groups/<groupId>/`，每个单聊是 `$DSH_HOME/dsh-bot-team/direct/<botId>/`（v0.8.0 的 `<dataDir>/<botId>` 会自动迁移）；旧的 `$DSH_HOME/bot-team` 已迁空（只允许残留 `.DS_Store`）；迁移后首次回复会为该 Bot 新建 session（`member.sessionId` 更新、群消息仍在、沙箱根等于新工作目录），旧 session 文件保留。
5. **自动冒烟**（临时开启 `smokeTest`）：`smoke-v11` 25 项全绿（含工具注册 8 个、workspace-write 沙箱、配额、health、单聊自动创建、分组创建/排序/删除回退、任务两条链路、依赖/优先级/环检测/自动解锁、一键派发/队列快照/默认不自动派发）。
6. **流式**：@ 一个 Bot，回复实时出现；断网/重连后消息补齐（SSE hello 会触发重拉）。
7. **评审/讨论**：评审回复有 verdict；讨论进度/轮次/总结/停止正常。
7b. **审批（v0.5.8）**：让 Bot 触发一次越界操作，群时间线出现「审批请求」卡片；点「去审批」打开该 Bot 会话，允许/拒绝后卡片状态同步；超时后标记已取消。
8. **权限**：所有 Bot 都能写文件/执行命令，但受群工作目录限制；`botSandbox: false` 时不显式写 workspace-write 档位。
9. **模型工具**：主会话可调用 `bot_team_list/send/review/discuss/create_group` 与 `bot_team_task_create/list/update`（含 `dispatch_ready`）。
10. **查看会话 / 导出**：成员会话可打开；导出 MD/HTML 内容完整。
10b. **任务中断/执行流**（v0.5.3）：派发一个长任务后点「中断」，任务变为 cancelled；点「执行流」能打开该任务 Bot 的 DSH 会话。
10c. **全局 Bot 管理**（v0.5.4）：左下角机器人图标可打开 Bot 管理弹窗，列表/编辑/新建正常；删除有群影响提示。
10d. **Bot 头像**（v0.5.9）：新建 Bot 点「随机生成」、选插画或上传图片，保存后消息/成员卡/Bot 库/@ 选择器显示正确；重启后头像仍在；无头像时按名称生成的机器人头像稳定。
10e. **群聊信息流**（v0.6）：同一 Bot 连续消息合并、头像/作者只在组首；跨 5 分钟出现时间分隔；悬停消息出现回复/复制/评审图标；回复后输入框上方出现引用条，发送并刷新后 `replyTo` 仍在；点击引用块定位原消息；上翻时新消息只出「N 条新消息」不强制滚底；「加载更早」保持阅读位置；头部「···」菜单可点击遮罩/Esc 关闭；@ 选择器可用 ↑/↓ + Enter；Bot 回复模型与 token 用量默认隐藏，悬停同时显示。
10f. **账号头像**（v0.6）：登录 DSH 后自己的消息显示账号头像/昵称；退出登录或图片加载失败时回退渐变字母。
10g. **群头像**（v0.6.1）：新建/编辑群可随机配色、选插画或上传图片；保存后左侧群列表与聊天顶部一致；刷新/重启后仍在。
10h. **深浅色主题**（v0.6.2）：在 DSH 设置切到 light/dark/system，Bot Team 页面、气泡、弹窗、输入框与滚动条即时跟随；深色下文字/边框可读，无需刷新。
10i. **单聊与分组（v0.7）**：
   - 新建 Bot 后页面直接打开它的单聊；侧栏「单聊」在「群聊」上方，每个 Bot 一行。
   - 单聊发消息不需要 @，Bot 会回复；刷新后消息仍在；单聊的「查看会话」「编辑 Bot」「导出 Markdown」正常。
   - 群聊「+」新建；「群聊」标题右侧文件夹图标可新建分组，分组可改名/删除；群编辑弹窗可选分组；右键群或行尾「···」可移动到分组、上移/下移。
   - 拖动群到另一分组、拖动分组本身可改变顺序；刷新后顺序保持。
   - 单聊 / 群聊 / 未分组 / 每个分组都可展开/收起，刷新后保持；侧栏收起成图标栏时单聊头像在上、群聊头像在下。
   - 聊天右上角的右侧面板按钮和面板头「»」都能收起/展开成员/任务/单聊信息面板，刷新后保持；≤1100px 时面板与按钮都自动隐藏。
   - 浏览器只刷新页面但 Host 仍是旧版时，侧栏会显示「Host 仍是旧版本」提示；重启 DSH 或对 bot-team 行 disable→enable 后恢复正常（v0.8 改名后旧行名失效，必须完整重启）。
10j. **设置与关于（v0.7）**：左侧栏「设置」打开两栏弹窗；「消息设置」保存/恢复默认仍生效；「关于」显示版本 / 包名（`dsh-bot-team`）/ 开发者（来自 `package.json`），刷新/重启后一致；窄屏下导航变横向。
11. **恢复**：重启 DSH 后数据仍在、Bot 会话可 resume（冒烟 recovery 检查）；排队标记为内存态，重启后任务仍 in_progress。

## 3. 若失败

- 记录 `smoke.jsonl` 中失败的 check id 与错误栈；常见原因：
  - `agent.followup` 需要完整 UserMessage（历史版本曾允许部分对象）；
  - `agents.resume` 不继承模型 → 必须复传 `agentOptions`；
  - `tools.restrict` 只对全局工具生效；Bot 递归 Team 工具仍由 deny 列表限制；
  - `ReadableStream.start()` 内 `this` 不是 Service 实例（SSE bug 复现点）；
  - domain per-record key 必须 `[a-zA-Z0-9_-]+`。
- 临时应急：插件管理页禁用 `bot-team`（数据保留），排除 DSH 升级问题后再启用。
- 涉及数据格式变化时：先备份 `$DSH_HOME/storages/bot_team` 与 `$DSH_HOME/dsh-bot-team/`（升级自旧版时备份 `$DSH_HOME/bot-team/`）。
