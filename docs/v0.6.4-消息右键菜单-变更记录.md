# v0.6.4 消息右键菜单 — 变更记录

> 状态：代码已完成，`node --check` 与 `node --test` 通过；待刷新页面后在浅色/深色下确认菜单位置与交互。
> 目标：消息不只有悬停图标，还可以在任意消息上点右键，从完整菜单里选择回复、复制等操作。

## 1. 菜单项

在任意普通消息（Bot / 人）上右键弹出：

| 菜单项 | 条件 | 行为 |
|---|---|---|
| 回复 | 消息不在生成中 | 与悬停「回复」一致：输入框出现引用条并聚焦 |
| 复制文本 | 消息有文本 | 复制原始 Markdown 文本，Toast「已复制消息」 |
| 复制为引用 | 消息有文本且不在生成中 | 复制 `> **作者**：正文` 形式的多行 Markdown 引用 |
| 定位原消息 | 仅回复消息且引用的原消息已加载 | 滚动到原消息并高亮 |
| 评审 | 非自己发送、不在生成中 | 打开评审弹窗，选择评审者 |
| 让作者修改 | 评审消息且已结束 | 让作者按该评审意见再交付 |
| 重试 | 错误消息 | 重试这条 Bot 回复（红色强调） |

同一消息的悬停工具栏与右键菜单共用 `messageActionList()` 生成动作，避免两套逻辑漂移；工具栏只显示 `hover !== false` 的图标按钮（仍是回复 / 复制文本 / 评审 / 让作者修改 / 重试），菜单额外提供「复制为引用」「定位原消息」。

生成中的消息右键仍会弹菜单，但「回复」「复制文本」为禁用态（灰色、不可点），等流式结束后恢复。

## 2. 交互细节

- **位置**：菜单以光标为左上角，`position: fixed` 渲染，自动收进视口并保留 8px 边距；高度按菜单项/分隔线精确估算，底部消息不会被裁掉。
- **关闭**：点菜单外任意位置（`mousedown` 捕获）、按 `Esc`、滚轮/触屏滑动、窗口 `resize`/失焦、切换群，都会关闭；时间线在 Bot 流式输出时的自动滚动不会把刚打开的菜单顶掉。
- **键盘**：菜单打开后自动聚焦第一个可用项，↑/↓ 在可用项间循环，`Tab` 关闭，`Esc` 关闭。
- **不再叠加原生菜单**：右键消息时 `preventDefault()`，避免浏览器菜单与自定义菜单同时出现。
- **保留原生菜单的场景**：
  - 右键落在**已选中的文字**上（方便「复制选中部分」）；
  - 右键落在消息里的**链接**上（方便「打开链接 / 复制链接」）。
- **切群/新消息**：切换群会立即清空菜单；打开中的消息菜单读取当前消息快照，流式结束后禁用项会恢复（组件优先用最新消息数组里的同 ID 消息）。
- 菜单复用 `--bt-*` token，浅色/深色主题自动跟随；`prefers-reduced-motion` 下无入场动画。

## 3. 实现

- `client.js`
  - `messageActionList()`：动作的唯一来源，返回 `{ key, icon, label, title, section, disabled, hover, danger, onSelect }`。
  - `buildQuoteMarkdown()`：生成带作者署名的 Markdown 引用；`placeMessageMenu()` / `messageMenuHeight()`：视口内定位与高度估算。
  - `MessageContextMenu`：`role="menu"` + `role="menuitem"`，带分隔线、禁用态、键盘导航与全局关闭监听。
  - `MessageRow`：新增 `onContextMenu` 事件与 `onCopyQuote` 回调，行元素挂 `onContextMenu`。
  - `BotTeamPage`：`messageMenu` 状态（含消息快照、光标坐标、`groupId`）、`openMessageMenu()`、`copyMessageQuote()`，并把菜单作为 `.bt-root` 子节点渲染（`fixed`，不受时间线裁剪）。
  - `GLOBAL_CSS`：`.bt-msg-menu` / `.bt-msg-menu-item` / 禁用态 / 危险项 / 分隔线 / reduced-motion。
- `test/message-context-menu.test.js`（10 条）：动作生成、流式禁用、引用/定位、评审/修改/重试、引用 Markdown、视口定位、菜单渲染与点击顺序、行事件、页面集成、CSS 兜底。

## 5. 注意

- 右键菜单只挂在普通聊天消息上；系统消息（评审/讨论提示）与「审批请求」卡片不弹此菜单。
- 手机/触屏没有右键：仍走原有的常显操作栏（`@media (hover: none)`），长按是否触发 `contextmenu` 取决于浏览器与系统。
- 菜单高度为按固定行高估算的结果；若以后菜单项改成多行或加入说明文字，需要同步更新 `messageMenuHeight()`，否则贴底时可能被视口裁掉几个像素。
