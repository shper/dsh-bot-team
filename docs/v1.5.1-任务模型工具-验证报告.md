## 1. 新增能力

### 1.1 任务模型工具（3 个，模型工具总数 5 → 8）

| 工具 | 作用 |
|---|---|
| `bot_team_task_create` | 建任务（标题/描述/验收标准/指派/评审者/优先级/依赖），可 `dispatch`+`wait` 一步派发并返回交付 |
| `bot_team_task_list` | 按「优先级→创建时间」排序列出任务，返回状态/优先级/依赖阻塞/ready/交付与评审摘录 |
| `bot_team_task_update` | `action`: dispatch / review / accept / request_changes / revise / cancel / update；dispatch/review/revise 可 wait，cancel 支持 `force` 级联 |

设计取舍：3 个工具 + action 枚举（而非 7 个细粒度工具），控制 schema/提示词成本；assignee/reviewer 按 **Bot 名**解析；
返回字段做 `undefined` 过滤（避免 lossless-JSON 校验失败）；路径与 UI 动作完全共用 service 层。

### 1.2 任务依赖（DAG）

- `dependsOn: string[]`（上限 10，同群校验，自依赖拒绝，**环检测**）；
- `ready = 所有依赖任务均为 accepted`；未就绪时 `dispatch/revise` 直接拒绝并返回阻塞清单（不消耗模型 token）；
- 任务被验收后**自动解锁**依赖者：重算 ready、广播 `task.updated`、写群系统消息「前置依赖解除」；不自动派发；
- 取消有依赖者的任务默认**拒绝**，`force: true` 时级联取消依赖者并返回 `cancelledDependents`。

### 1.3 优先级

- `priority: urgent | high | normal | low`（默认 normal）；任务面板与 `task_list` 按 **priority rank → createdAt** 排序；
- 卡片显示彩色优先级 chip；Web UI 排序与模型工具排序一致；
- 不做抢占式调度（保持"显式派发"的确定性，留给 v2 任务队列）。

### 1.4 UI / 编辑

- 任务对话框新增：优先级下拉、**依赖任务多选**（同群任务）、编辑模式（`task.update`）；
- 任务卡片新增：优先级 chip、阻塞原因（`阻塞：X（pending）`）、派发按钮在未就绪时置灰并提示、编辑按钮。

### 1.5 数据

- `tasks` 表新增 `priority`、`dependsOn`；SCHEMA_VERSION **3 → 4**，迁移给存量任务补默认值。

## 4. 本轮修复的缺陷

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| B7 | **DSH 崩溃**：任务被验收且存在依赖者时宿主进程退出（15:37–15:38 连续 3 次），错误 `this.systemMessage is not a function` | `unblockDependents` 调用了一个不存在的方法（`systemMessage` 在 Engine 上，不在 Service 上）；该异常发生在 Engine 的异步 `taskHook`（async 函数）里，同步 try/catch 抓不到 → unhandledRejection → host fatal exit 1 | ① 改为 `this.engine.systemMessage(...)`；② Engine 调用 taskHook 时对返回 Promise 注册 `.catch()`；③ `onTaskJobFinished` 整体 try/catch，任务记账失败只 warn 不崩宿主 |
| B8 | `bot_team_task_list` 返回 `value is not lossless JSON` | 任务摘要对象含 `undefined` 字段（reviewer/deliverable/review 等） | 输出统一走 `compactObject()` 过滤 undefined（与其它工具一致） |

> DSH 崩溃后自身恢复了 profile（生成 `cordis.patch.yml.bak-1793000293751` 并移除插件行）；重新 `remove_bundle → install_bundle` 后恢复。

## 5. 已知限制 / 后续

- 优先级只影响排序/展示，不抢占调度（v2 任务队列再考虑）；
- 依赖只支持「全部 accepted」，不支持条件/或依赖；
- 任务编辑不支持改 status（走动作）；无删除（可取消）；
- 任务模型工具暂无批量派发（按优先级一键派发）——可作为 v1.5.2 小项；
- 完整 i18n、按 capability 精确收敛工具可见性仍是后续项。
