- 保持不变（有数据/契约含义）：storage domain `bot_team`、工具名 `bot_team_*`、路由 `/api/bot-team.*`、localStorage 键 `bot-team.*`。

## 数据目录

新增 `config.dataDir`，默认 `$DSH_HOME/dsh-bot-team`：

| 路径 | 用途 |
|---|---|
| `<dataDir>/bots/<botId>/BOT.md` | 人格与工作规范 |
| `<dataDir>/<botId>/` | 单聊工作目录（`workspaceCwd` 留空时的默认值） |
| `<dataDir>/groups/<groupId>/` | 群聊工作目录（`workspaceCwd` 留空时的默认值） |

- 新建群 / 单聊时自动创建目录并写入 `workspaceCwd`；Agent 启动前再 ensure 一次，目录被删也能恢复。
- 群编辑弹窗把工作目录清空即回到该群的默认目录。
- DSH 把 session 的沙箱根固定在创建时的 `header.cwd`，且拒绝把已有 session 换到另一个 cwd。因此当工作目录与 session cwd 不一致时（升级迁移或手动改工作目录），Host 会结束旧 agent、为同一个群成员新建 session（`session-botteam-<uuid>`），把 `member.sessionId` 切过去；群消息与任务都在 domain 里，对话不丢，但该 Bot 的 DSH 会话历史从新 session 重新开始，旧 session 文件保留在 `$DSH_HOME/sessions/`。
- resume 后仍调用 `ctx.workingDirectory.set()` 校正工作目录投影（正常情况下是 no-op）。

## 旧布局迁移

启动时（默认布局且 `migrateLegacyLayout` 未关闭）执行一次幂等迁移：

1. `$DSH_HOME/bot-team/bots` → `<dataDir>/bots`（目标已存在时逐个 Bot 合并）。
2. `workspaceCwd` 仍位于 `$DSH_HOME/bot-team/` 下的群/单聊：目录移到新默认位置，并改写记录；外部自定义工作目录不动。
3. 旧根目录为空则删除（仅清理 Finder 的 `.DS_Store`）。

迁移失败只记 warn，下一次启动重试；标准布局之外（自定义 `dataDir`/`botsDir`）不自动迁移。
