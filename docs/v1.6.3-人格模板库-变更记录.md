# v1.6.3 人格模板库 — 变更记录

> 状态：代码已完成，`node --check` 通过；待刷新页面后在浅色/深色下确认视觉效果。
> 目标：新建/编辑 Bot 时，`BOT.md` 不再只有一个「插入模板」，而是可以按角色挑一套现成人格。

## 1. 模板内容

`client.js` 里新增 `PERSONA_TEMPLATES`（9 项），每项包含 `title` / `summary` / `body`，`body` 是可直接写入 `BOT.md` 的完整 Markdown，统一保留两节标题：

- `## 人格`：你是谁、怎么说话、重视什么；
- `## 工作规范`：怎么做事、输出格式、边界。

| # | 模板 | 适合 |
|---|---|---|
| 1 | 通用助手（推荐） | 日常问答、杂项任务 |
| 2 | 代码实现工程师 | 改代码、补实现、自测 |
| 3 | 代码评审员 | PR / diff 评审，按阻塞/风险/建议分级 |
| 4 | 需求分析师 | 拆需求、定范围、写验收标准 |
| 5 | 技术调研员 | 选型对比、带来源的结论 |
| 6 | 测试工程师 | 测试范围、用例、缺陷复现 |
| 7 | 文档写作者 | README、使用指南、变更记录 |
| 8 | 批判质疑者 | 方案评审里的反方、风险挑刺 |
| 9 | 数据分析师 | 指标口径、数据结论、不确定性 |

新增模板只需往 `PERSONA_TEMPLATES` 里加一项，菜单会自动出现。

## 2. 交互

- 「插入模板」右侧加 `▾`，点击向上弹出「人格模板库」菜单（可滚动，9 项都带一句话说明）；
- **空内容**：直接填入所选模板；
- **已有内容**：追加到末尾；
- **末尾正好是某个旧模板**：替换该模板，而不是叠第二份；
- 内容里已包含某个模板时，菜单项显示「已包含」；点击不会重复插入；
- 点菜单外、按 `Esc` 关闭（`Esc` 只关菜单，不会连带关闭整个 Bot 弹窗）；
- 插入后焦点回到 textarea，光标停在末尾，footer 显示「已插入「X」模板」提示，继续输入时提示消失。
